# NeetCode Solutions

A collection of my solutions to problems from the **NeetCode** roadmap, implemented primarily in **Java**.

This repository documents my progress in Data Structures and Algorithms and serves as a reference for concepts, problem-solving patterns, and optimized solutions.

The problems are organized according to common DSA patterns and topics:

- Greedy
